# Paintable face textures

Edit these PNGs in any image editor (Photoshop, Krita, Aseprite, even Preview)
to add decals and coloring to the 3D workstation. The site loads them at
runtime — save the file, refresh the page, done. Each ships as a flat
base-color canvas, so the scene looks unchanged until you paint.

Keep the filenames and aspect ratios; resolution can be scaled up if you want
finer detail (2× etc. is fine).

| File | Object / face | Size | Scale |
| --- | --- | --- | --- |
| `monitor-bezel.png` | CRT front bezel (all four bars, one image) | 1060×810 | 200 px/unit |
| `keyboard-top.png` | Keyboard base, top face | 920×370 | 200 px/unit |
| `mouse-top.png` | Mouse body, top face | 288×432 | 400 px/unit |
| `radio-front.png` | Radio body, front face | 500×740 | 400 px/unit |

## Guides

`guides/*-guide.png` are annotated copies — **never loaded by the site**, just
reference. Open one as a layer under/over your edit to see where not to paint:

- **Blue hatch** (monitor): the screen opening — a hole, never rendered.
- **Red hatch/outlines**: zones covered by other meshes (keycaps, mouse
  buttons + wheel, radio readout panel + speaker slits, power button,
  post-it). Paint there and it simply won't be visible.

## Orientation

- Monitor and radio: the image maps as you'd expect looking straight at it.
- Keyboard and mouse (top faces): top of the image = far edge (away from the
  viewer), as if looking down at the desk from the chair.

## Notes

- Base colors: cream `#f4eede` (monitor/keyboard/mouse), grey `#b2b4b4`
  (radio). The material color is white once the texture loads, so what you
  paint is what renders (lambert-shaded by the scene lights).
- Wiring lives in `src/app/components/Scene3D.tsx` (`paintedMat`, `faceMats`,
  `remapFaceUV`). To texture another face of a box, pass a different face
  index: 0 +x, 1 −x, 2 +y (top), 3 −y, 4 +z (front), 5 −z.
- Templates were generated by a script; regenerate blank ones by re-running
  it if you ever want to start over (or just flood-fill with the base color).
